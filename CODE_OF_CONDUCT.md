# Code of Conduct / Code de conduite

**EN** — Be kind, be patient, assume good faith. Welcome beginners: many users are discovering SSH and networking
for the first time. Harassment, insults and discrimination are not tolerated. Maintainers may edit or remove
comments, issues and contributions that break these rules, and may block repeat offenders.

**FR** — Soyez bienveillant, patient, et partez du principe que l'autre est de bonne foi. Accueillez les débutants :
beaucoup découvrent SSH et le réseau. Le harcèlement, les insultes et les discriminations ne sont pas tolérés.
Les mainteneurs peuvent modifier ou supprimer les commentaires, issues et contributions qui enfreignent ces règles,
et bloquer les récidivistes.

This text is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
